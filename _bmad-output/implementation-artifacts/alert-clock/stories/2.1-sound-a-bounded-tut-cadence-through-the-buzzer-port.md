<intent-contract>

## Intent

**Problem:** The device has no bounded buzzer adapter, so future alert occurrences cannot produce audible output without risking blocking timing or unsafe GPIO ownership.

**Approach:** Add one device-layer `BuzzerPort` with low-first initialization, active-high non-blocking cadence, wrap-safe deadlines, bounded edge resynchronization, idempotent silence, and named failure results. Construct it from main using named config constants.

## Boundaries & Constraints

**Always:** Use GP15, 180 ms high, 220 ms low, active-high injection from `config.py`; use `ticks_add`/`ticks_diff`; drive low before exposure; keep failure results secret-free and recoverable; keep pure alert code free of hardware imports.

**Never:** Do not implement scheduler, active-alert state, display takeover, touch controls, stop/postpone/auto-stop, persistence, or device validation claims. Do not duplicate GPIO or cadence literals outside config/composition wiring.

</intent-contract>

**Acceptance Criteria:**
- Given a configured composition root, when it constructs the port, then GP15, active-high, 180 ms, and 220 ms are injected from config.
- Given a new port, when initialization completes, then output is low first and result is named and secret-free.
- Given an idle initialized port, when `tick(now, True)` runs, then it drives high immediately and schedules high phase end at `now + 180`.
- Given a high phase deadline, when `tick` runs, then it drives low and schedules the low phase end at `now + 220`; late calls emit at most one edge and resynchronize.
- Given silence or `sounding=False`, when called, then output stays low and cannot reassert high.
- Given tick wrap or a failed drive, when the port operates, then wrap-safe timing and recoverable named failure behavior hold.

## Design Notes

The port treats failed output state as unknown. A failed edge gets one best-effort low attempt, but the port remains unavailable until `initialize()` performs a fresh low-first sequence. A late tick toggles at most once and sets the next deadline from the current time, preventing edge replay.
