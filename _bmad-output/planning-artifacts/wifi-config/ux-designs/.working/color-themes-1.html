Wi-Fi Config UI — Accent Color Variations
Base palette (bg / surface / border / text / danger / success) is locked across all six variations. Only the accent hue changes — used for the primary Connect/Save button fill, the focused input border, and the selected SSID row border + checkmark. Mock is the Setup page's SSID-picker screen, served over the temporary open AP during first boot / recovery.
